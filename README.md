# Бот-квиз для веб-студии (Telegram, Python 3 + aiogram 3)

Бот проводит клиента по сценарию «Заказать новый сайт / Доработать сайт / Продвижение / Примеры работ / Контакты»,
собирает контакты и отправляет готовую заявку менеджеру.

## Запуск

```bash
cd site_bot
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # вписать BOT_TOKEN и ADMIN_IDS
python3 run_bot.py
```

Свой Telegram ID для `ADMIN_IDS` можно узнать командой `/myid` в боте.

## Структура

```
run_bot.py                  — точка входа, сборка всех деталей
content/scenario.json       — ВЕСЬ контент бота: тексты, кнопки, вопросы, ветки, портфолио, цены
content/backups/            — автокопии scenario.json перед каждой правкой из админки (последние 30)
data/zayavki.sqlite3        — база заявок
masterskaya/
  nastroyki.py              — чтение .env
  shkatulka.py              — загрузка/сохранение scenario.json
  kladovka.py               — заявки в SQLite, выгрузка в CSV
  knopki.py                 — callback-данные и клавиатуры меню
  verstak.py                — движок сценария (ветки, «Назад», мультивыбор, ручной ввод, разделы сайта)
  sdacha.py                 — сводка заявки, ориентировочная смета, отправка менеджеру
  handlers/vhod.py          — /start, блок конфиденциальности, главное меню, контакты
  handlers/dialog.py        — кнопки и ввод внутри анкеты
  handlers/vitrina.py       — «Примеры наших работ»
  handlers/masterovoy.py    — админ-панель и кнопки под заявками
```

Сценарий не зашит в код: движок читает ветки (`flows`) и шаги (`steps`) из `scenario.json`.
Типы шагов: `single` (один выбор), `multi` (несколько + «Продолжить»), `sections` (категории разделов
с вложенным выбором), свободный ввод (`free_input`). У варианта могут быть: `input` — уточняющий вопрос,
`file` — загрузка файла, `exclusive` — снимает остальные галочки, `flow` — переход в другую ветку,
`price` — надбавка к смете. Условие показа шага — `show_if` (так сделан вопрос 3.4 в продвижении).

## Описание решения (п. 4 задания)

### 1. Ссылка на бота / демонстрация
`https://t.me/<имя_бота>` — указать после регистрации бота в @BotFather.

### 2. Платформа / технология
Собственное решение: Python 3.11+, aiogram 3, SQLite. Никаких платных конструкторов.
Бот работает на любом VPS или домашнем сервере, данные клиентов остаются у заказчика.

### 3. Дополнительная функция — ориентировочный расчёт стоимости + приём заявок менеджерами

**Что сделано.** В конце ветки «Заказать новый сайт» клиент сразу видит «Ориентировочная стоимость: от N ₽».
Сумма складывается из базовой цены ветки (товары / услуги / товары+услуги / иное), надбавок за выбранные
опции (оплата, доставка, 1С, функционал, дизайн и т.д.) и цены за каждую отмеченную страницу.
Та же сумма приходит менеджеру в карточке заявки.

**Какую задачу решает.** Главный вопрос клиента — «сколько стоит?». Без ответа он уходит считать к
конкурентам. Предварительная цифра удерживает клиента и отсеивает нецелевые заявки с несопоставимым
бюджетом, а менеджер видит ожидания по цене ещё до звонка.

**Чем полезно заказчику.** Цены настраиваются из админки (база, надбавка за каждый вариант, цена страницы),
расчёт можно выключить одной кнопкой.

Дополнительно к этому:
- заявки уходят в общий чат менеджеров с кнопками «🙋 Взять в работу» → «✅ Закрыть»: видно, кто
  ведёт клиента, и заявку не возьмут двое;
- файл ТЗ, загруженный клиентом, пересылается менеджеру вместе с заявкой;
- «Иное» в примерах работ — запрос клиента сразу уходит менеджеру;
- выгрузка всех заявок в Excel (CSV).

### 4. Администрирование
Админ-панель встроена прямо в бота — команда `/admin` (доступна только ID из `ADMIN_IDS`).
Знание программирования не требуется, правки применяются мгновенно, без перезапуска.

| Раздел | Что можно менять |
|---|---|
| 📝 Тексты и информационные блоки | блок конфиденциальности (с ссылкой на политику), приветствие, контакты, финальное «спасибо», тексты раздела «Примеры работ», подсказки об ошибках |
| 🔘 Надписи на кнопках меню | все кнопки главного меню, «Назад», «Продолжить», «Готово» и др. |
| ❓ Вопросы и варианты ответов | текст любого вопроса, подсказку под ним, надпись каждого варианта, уточняющие вопросы, названия категорий разделов |
| 🗂 Примеры работ | вступительный текст по сфере, добавление работы (`Название \| ссылка`), удаление |
| 💰 Расчёт стоимости | вкл/выкл, базовые цены, цена страницы (цены вариантов — в разделе «Вопросы») |
| 📥 Последние заявки | просмотр, взять в работу, закрыть |
| 📤 Выгрузить заявки | файл для Excel |
| ⚙️ Куда приходят заявки | добавить бота в группу и написать там `/set_chat` — заявки пойдут в группу; или вернуть в личку |

Форматирование (жирный, курсив, ссылки), сделанное штатными средствами Telegram, сохраняется.
Перед каждой правкой бот делает резервную копию `scenario.json`, так что любую ошибку можно откатить.
Добавление новых вопросов и веток — правкой `scenario.json` (структура описана выше), без изменения кода.

## Найденные в сценарии неточности и как они исправлены

1. В «Примерах работ» блок «Спорт / отдых / тренеры» продублирован, а его текст — «по тематике еды
   и кулинарии». Оставлен один блок с текстом «по тематике спорта и отдыха».
2. У вопроса «Что будет приоритетом?» (Товары + Услуги) не было кнопки «Назад» — добавлена, как во всех шагах.
3. Для «Иное (ввести вручную)» в «Что вы хотите разместить на сайте?» не указано продолжение.
   После ввода клиент проходит «Разделы сайта» → «Дизайн» → «Пример сайта» → финальные вопросы.
4. В «Сейчас вы уже что-то продвигаете?» варианты «Никогда не продвигали» и «Затрудняюсь» ведут сразу
   в финал. Чтобы не было противоречий, они снимают остальные галочки. Если клиент вернётся «Назад»
   и выберет другие варианты, пропущенные вопросы снова появятся.
5. Вопрос 3.4 «Вам кто-то уже помогал?» показывается только при выборе одного из первых пяти ответов
   в 3.3, как указано в сценарии.
6. Телефон проверяется на корректность (10–15 цифр), можно прислать карточку контакта.
7. Ссылки на скриншоты работ в сценарии ещё не переданы — работы заведены без ссылок, ссылки
   добавляются из админки.
